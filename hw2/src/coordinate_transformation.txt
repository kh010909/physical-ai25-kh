=== COORDINATE TRANSFORMATION PARAMETERS ===

This file contains the transformation between 3D Habitat coordinates (X, Z)
and pixel coordinates in the saved map.png file.

Habitat Coordinate Ranges:
  X: [-3.554479, 6.688393]
  Z: [-5.671297, 10.652814]

Image Properties:
  Width:  3600 pixels
  Height: 2400 pixels
  DPI:    300

Scaling Factors:
  X scale: 351.463912 pixels/habitat_unit
  Z scale: 147.021786 pixels/habitat_unit

Conversion Formulas:
  From Habitat (x, z) to Pixel (px, py):
    px = (x - -3.554479) * 351.463912
    py = (z - -5.671297) * 147.021786

  From Pixel (px, py) to Habitat (x, z):
    x = px / 351.463912 + -3.554479
    z = py / 147.021786 + -5.671297

Note: The Y-axis in the image corresponds to the Z-axis in Habitat coordinates.
The origin (0,0) in image coordinates is at the top-left corner.
